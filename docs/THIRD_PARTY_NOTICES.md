# Симуляторы и открытый реестр

Демонстрационные ИНН `7700000001`–`7700000005` и сбойный `7700000099` обслуживаются локальными фикстурами. Так сценарии хакатона не зависят от сети.

Любой другой ИНН запрашивается в открытом поиске ФНС на [egrul.nalog.ru](https://egrul.nalog.ru/). Оттуда берутся название, ОГРН, КПП, руководитель, дата регистрации и регион. Улица и дом этот поиск не отдаёт. Это не подписанная выписка.

| Имя в продукте | Что это на самом деле |
|---|---|
| ЕГРЮЛ / ЕГРИП | Для настоящего ИНН — публичный поиск egrul.nalog.ru. Для демо-ИНН — локальная фикстура. |
| БКИ | Открытого поиска нет. Отчёт бюро выдаётся только с согласия компании, поэтому для настоящего ИНН история не запрашивается и не подменяется «чистой». Для демо-ИНН история синтетическая. |
| ФНС «Прозрачный бизнес» | Для настоящего ИНН — открытая карточка pb.nalog.ru: адрес, ОКВЭД, статус, капитал, а если ФНС их опубликовала — численность, режим, недоимка и отчётность. Для демо-ИНН — фикстура. |

Платных API и корпоративных систем банка нет.
